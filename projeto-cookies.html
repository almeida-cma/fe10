1 O botão "Ler cookies" mostra undefined

O que deveria acontecer Clicar em "Ler cookies" mostra o conteúdo atual de document.cookie na caixa de resultado.
O que acontece hoje Clicar mostra "undefined" na tela, mesmo que existam cookies gravados.
No console (F12): (nenhum erro — bug silencioso)
Onde olhar A função lerCookies() usa document.cookies (com "s"). O correto é document.cookie (sem "s").
HTML Estrutura do componente
<div class="demo-ler"> <h3>Ler cookies</h3> <p>Este componente deveria mostrar os cookies atuais.</p> <button onclick="lerCookies()">Ler cookies agora</button> <div class="terminal" id="demo-ler"></div> </div>
CSS Estilo do componente
.demo-ler { background: #ffffff; border: 2px solid #e2e8f0; border-radius: 12px; padding: 20px; max-width: 480px; } .demo-ler h3 { font-size: 1rem; margin-bottom: 10px; color: #1e1b4b; } .demo-ler p { font-size: 0.86rem; color: #64748b; margin-bottom: 14px; } .demo-ler button { background: #7c3aed; color: #ffffff; border: none; padding: 9px 18px; border-radius: 8px; font-weight: 700; cursor: pointer; font-size: 0.85rem; margin-bottom: 10px; } .demo-ler .terminal { background: #0b0518; color: #a5f3fc; padding: 10px 14px; border-radius: 8px; font-family: 'Courier New', monospace; font-size: 0.78rem; min-height: 40px; word-break: break-all; }
JS ❌ Código com bug — lerCookies()
function lerCookies() { var atual = document.cookies; // ❌ BUG: "cookies" com "s" document.getElementById("demo-ler").innerHTML = atual ? "Cookies: " + atual : "(nenhum cookie)"; }
JS ✅ Código correto — lerCookies()
function lerCookies() { var atual = document.cookie; // ✅ CORRETO: "cookie" sem "s" document.getElementById("demo-ler").innerHTML = atual ? "Cookies: " + atual : "(nenhum cookie)"; }
🔍 Veja no DevTools real Abra o F12 → Application → Storage → Cookies. Clique em "Ler cookies agora". O terminal mostra "undefined" porque document.cookies não existe. Depois de consertar para document.cookie, o terminal mostra os cookies reais.

2 O botão "Apagar tema" não apaga

O que deveria acontecer Clicar em "Apagar tema" remove o cookie tema do navegador.
O que acontece hoje O cookie continua gravado depois de clicar. A tabela do DevTools mostra a linha do tema ainda presente.
No console (F12): (nenhum erro — bug silencioso)
Onde olhar A função apagarTema() faz document.cookie = "tema=" — mas esquece de definir max-age=0 e path=/. Sem isso, o navegador não remove.
HTML Estrutura do componente
<div class="demo-apagar"> <h3>Apagar tema</h3> <label>Valor do tema</label> <input type="text" id="demo-tema-apagar" value="escuro"> <div class="btns"> <button onclick="gravarTemaParaApagar()">Gravar tema</button> <button onclick="apagarTema()">Apagar tema</button> </div> <div class="terminal" id="demo-tema-resultado"></div> </div>
CSS Estilo do componente
.demo-apagar { background: #ffffff; border: 2px solid #e2e8f0; border-radius: 12px; padding: 20px; max-width: 480px; } .demo-apagar h3 { font-size: 1rem; margin-bottom: 10px; color: #1e1b4b; } .demo-apagar label { display: block; font-weight: 700; font-size: 0.82rem; color: #334155; margin-bottom: 4px; } .demo-apagar input { width: 100%; padding: 9px 12px; border: 1px solid #cbd5e1; border-radius: 6px; font-size: 0.9rem; margin-bottom: 8px; } .demo-apagar .btns { display: flex; gap: 8px; flex-wrap: wrap; margin-bottom: 10px; } .demo-apagar button { background: #7c3aed; color: #ffffff; border: none; padding: 9px 16px; border-radius: 8px; font-weight: 700; cursor: pointer; font-size: 0.82rem; } .demo-apagar .terminal { background: #0b0518; color: #a5f3fc; padding: 10px 14px; border-radius: 8px; font-family: 'Courier New', monospace; font-size: 0.78rem; min-height: 40px; }
JS ❌ Código com bug — apagarTema()
function apagarTema() { document.cookie = "tema="; // ❌ BUG: falta max-age=0 e path=/ document.getElementById("demo-tema-resultado").innerHTML = "Tentativa de apagar tema enviada"; } // Função separada para gravar (sem bug) function gravarTemaParaApagar() { var valor = document.getElementById("demo-tema-apagar").value; document.cookie = "tema=" + encodeURIComponent(valor) + "; max-age=3600; path=/"; document.getElementById("demo-tema-resultado").innerHTML = "Cookie tema=" + valor + " gravado"; }
JS ✅ Código correto — apagarTema()
function apagarTema() { document.cookie = "tema=; max-age=0; path=/; SameSite=Lax"; // ✅ CORRETO document.getElementById("demo-tema-resultado").innerHTML = "Cookie tema apagado"; } function gravarTemaParaApagar() { var valor = document.getElementById("demo-tema-apagar").value; document.cookie = "tema=" + encodeURIComponent(valor) + "; max-age=3600; path=/"; document.getElementById("demo-tema-resultado").innerHTML = "Cookie tema=" + valor + " gravado"; }
🔍 Veja no DevTools real Abra o F12 → Application → Storage → Cookies. Clique em "Gravar tema" — o cookie aparece. Clique em "Apagar tema" — o cookie continua. Só depois de consertar para max-age=0 o cookie desaparece.

3 O botão "Gravar tema" não grava nada

O que deveria acontecer Clicar em "Gravar tema" define um cookie tema com o valor digitado no input.
O que acontece hoje Clicar no botão não faz nada. O terminal continua vazio.
No console (F12): Uncaught TypeError: Cannot read properties of null (reading 'value') at gravarTema (projeto-cookies.html:XX)
Onde olhar A função gravarTema() busca getElementById("tema-escolhido"). Mas o input tem id="tema". O navegador devolve null e quebra ao ler .value.
HTML Estrutura do componente
<div class="demo-gravar"> <h3>Gravar tema</h3> <label>Valor do tema</label> <input type="text" id="tema" value="escuro"> <button onclick="gravarTema()">Gravar tema</button> <div class="terminal" id="demo-gravar-resultado"></div> </div>
CSS Estilo do componente
.demo-gravar { background: #ffffff; border: 2px solid #e2e8f0; border-radius: 12px; padding: 20px; max-width: 480px; } .demo-gravar h3 { font-size: 1rem; margin-bottom: 10px; color: #1e1b4b; } .demo-gravar label { display: block; font-weight: 700; font-size: 0.82rem; color: #334155; margin-bottom: 4px; } .demo-gravar input { width: 100%; padding: 9px 12px; border: 1px solid #cbd5e1; border-radius: 6px; font-size: 0.9rem; margin-bottom: 8px; } .demo-gravar button { background: #7c3aed; color: #ffffff; border: none; padding: 9px 18px; border-radius: 8px; font-weight: 700; cursor: pointer; font-size: 0.85rem; margin-bottom: 10px; } .demo-gravar .terminal { background: #0b0518; color: #a5f3fc; padding: 10px 14px; border-radius: 8px; font-family: 'Courier New', monospace; font-size: 0.78rem; min-height: 40px; }
JS ❌ Código com bug — gravarTema()
function gravarTema() { var valor = document.getElementById("tema-escolhido").value; // ❌ BUG: id errado document.cookie = "tema=" + encodeURIComponent(valor) + "; max-age=3600; path=/"; document.getElementById("demo-gravar-resultado").innerHTML = "Cookie tema=" + valor + " gravado"; }
JS ✅ Código correto — gravarTema()
function gravarTema() { var valor = document.getElementById("tema").value; // ✅ CORRETO: id="tema" document.cookie = "tema=" + encodeURIComponent(valor) + "; max-age=3600; path=/"; document.getElementById("demo-gravar-resultado").innerHTML = "Cookie tema=" + valor + " gravado"; }
🔍 Veja no DevTools real Abra o F12 → Console. Clique em "Gravar tema". Aparece TypeError: Cannot read properties of null. Isso significa que getElementById("tema-escolhido") não achou o elemento. O input tem id="tema", não "tema-escolhido".
