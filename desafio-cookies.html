✅ O que o projeto precisa ter

Requisitos obrigatórios
  • Banner LGPD que aparece na primeira visita e não aparece mais depois do consentimento.
  • 3 categorias de cookies com toggles individuais: Essenciais (sempre ativos), Análise, Marketing.
  • Botões "Aceitar todos", "Apenas essenciais" e "Salvar seleção".
  • Um painel de status mostrando quais categorias estão ativas no momento.
  • Um botão "Reabrir preferências" para o usuário mudar de ideia.
  • As escolhas precisam ser gravadas em cookies (cada categoria em um cookie separado ou um cookie JSON).

📋 Checklist do professor

O que será verificado
  • Site abre no GitHub Pages e funciona.
  • Banner aparece na primeira visita.
  • Ao aceitar, banner desaparece e preferências são gravadas.
  • Ao recarregar, banner não aparece novamente.
  • Cada categoria pode ser ativada individualmente.
  • O painel de status reflete o estado atual dos cookies.
  • O botão "Reabrir preferências" permite alterar as escolhas.
  • README com link do GitHub Pages + descrição.

🔍 Como testar antes de entregar

Verifique cada item no DevTools real (F12)
  1. Abra o site no Live Server. O banner deve aparecer no rodapé.
  2. Abra o DevTools (F12) → aba Application → Storage → Cookies. Não deve haver nenhum cookie de consentimento ainda.
  3. Clique em "Aceitar todos". O banner desaparece. No DevTools, os cookies consentimento_lgpd, cat_analise e cat_marketing aparecem com valor sim ou todos.
  4. Recarregue a página (F5). O banner não deve aparecer. O painel de status mostra Análise e Marketing como "Ativos".
  5. Clique em "Reabrir preferências". O banner volta. Desmarque "Marketing" e clique em "Salvar seleção".
  6. No DevTools, o cookie cat_marketing deve estar com valor nao. Recarregue e confirme que o painel mostra Marketing como "Bloqueado".
  7. Publique no GitHub Pages. Abra o link em uma aba anônima. O banner deve aparecer de novo (porque é uma sessão nova, sem cookies).
  8. No README do repositório, confirme que o link do GitHub Pages está lá e abre.

JS script.js
// ============================================================ // BANNER LGPD — script completo para você adaptar // ============================================================ // 1. Ao carregar a página, verificar se o usuário já consentiu. // Se sim, esconder o banner e mostrar o painel de status. window.addEventListener("load", function() { var consentimento = getCookie("consentimento_lgpd"); if (consentimento) { document.getElementById("banner").classList.add("oculto"); atualizarPainel(); } }); // 2. Aceitar todos os cookies (essenciais + análise + marketing) function aceitarTodos() { document.cookie = "consentimento_lgpd=todos; max-age=31536000; path=/"; document.cookie = "cat_analise=sim; max-age=31536000; path=/"; document.cookie = "cat_marketing=sim; max-age=31536000; path=/"; document.getElementById("banner").classList.add("oculto"); atualizarPainel(); } // 3. Aceitar apenas os essenciais (sempre ativos) function aceitarApenasEssenciais() { document.cookie = "consentimento_lgpd=essenciais; max-age=31536000; path=/"; document.cookie = "cat_analise=nao; max-age=31536000; path=/"; document.cookie = "cat_marketing=nao; max-age=31536000; path=/"; document.getElementById("banner").classList.add("oculto"); atualizarPainel(); } // 4. Salvar a seleção do usuário (customizada) function salvarSelecao() { var analise = document.getElementById("chk-analise").checked ? "sim" : "nao"; var marketing = document.getElementById("chk-marketing").checked ? "sim" : "nao"; document.cookie = "consentimento_lgpd=custom; max-age=31536000; path=/"; document.cookie = "cat_analise=" + analise + "; max-age=31536000; path=/"; document.cookie = "cat_marketing=" + marketing + "; max-age=31536000; path=/"; document.getElementById("banner").classList.add("oculto"); atualizarPainel(); } // 5. Reabrir o banner para o usuário mudar de ideia function reabrirPreferencias() { document.getElementById("banner").classList.remove("oculto"); } // 6. Atualizar o painel de status com o estado atual dos cookies function atualizarPainel() { var analise = getCookie("cat_analise") === "sim" ? "Ativo" : "Bloqueado"; var marketing = getCookie("cat_marketing") === "sim" ? "Ativo" : "Bloqueado"; document.getElementById("painel-status").innerHTML = "<p><strong>Essenciais:</strong> Sempre ativos</p>" + "<p><strong>Análise:</strong> " + analise + "</p>" + "<p><strong>Marketing:</strong> " + marketing + "</p>"; } // 7. Função auxiliar para ler um cookie pelo nome function getCookie(nome) { var match = document.cookie.match(new RegExp("(^| )" + nome + "=([^;]+)")); return match ? decodeURIComponent(match[2]) : null; }
