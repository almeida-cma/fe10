🧠 O que diabos é um Cookie? (A analogia do parque de diversões)

Imagine que a internet tem "amnésia": toda vez que você recarrega uma página, o site esquece completamente quem você é. Para resolver isso, o site coloca uma "pulseirinha de papel" no seu pulso. Essa pulseirinha é o Cookie!

🏷️ 1. O Nome e o Valor Na pulseirinha está escrito algo como tema = escuro ou usuario = Lucas. É um par de texto simples.
⏰ 2. A Data de Validade A pulseira pode durar só até você fechar a aba (Sessão) ou valer por 1 ano inteiro (Persistente). Quem manda é o max-age.
🔒 3. A Regra do Lugar Com path=/, a pulseira vale em qualquer brinquedo (página) daquele parque (site).

🎨 Tema claro/escuro memorizado com Cookie

Aqui aprendemos a gravar e recuperar o estado visual de um componente. Quando o usuário escolhe o tema escuro, gravamos tema=escuro. Quando a página recarrega, o JavaScript lê o cookie e reaplica o visual antes mesmo do usuário notar!

🔍 Raio-X do Código: O que cada pedaço faz?

document.cookie = ...
É o comando oficial do navegador para salvar uma memória. Atenção: no singular (não existe cookies com "s").
max-age=31536000
De onde veio esse número gigante? É a quantidade de segundos em 1 ano inteiro!
60 segundos × 60 minutos × 24 horas × 365 dias = 31.536.000 segundos. Isso faz o cookie durar um ano!
path=/
Diz que o cookie vale para todo o site (raiz /), e não apenas para uma página específica.
SameSite=Lax
Uma trava moderna de segurança e privacidade do navegador para impedir que outros sites roubem ou usem seu cookie indevidamente.

<div class="card" id="card-tema"> <h3>Bem-vindo ao laboratório</h3> <p>Clique no botão para alternar o tema.</p> <button onclick="alternarTema()">Alternar tema</button> </div>
CSS As duas "roupas" do componente

JS Salvando e Lendo o Cookie
// PASSO 1: Ao carregar a página, checa se já existia uma escolha salva window.addEventListener("load", function() { var temaSalvo = getCookie("tema"); if (temaSalvo === "escuro") { document.getElementById("card-tema").classList.add("tema-escuro"); } }); // PASSO 2: Ao clicar no botão, inverte a classe e grava o novo cookie function alternarTema() { var card = document.getElementById("card-tema"); // toggle adiciona se não tiver, e remove se já tiver! var estaEscuro = card.classList.toggle("tema-escuro"); // Se está escuro grava "escuro", senão grava "claro" var valor = estaEscuro ? "escuro" : "claro"; // Grava o cookie com validade de 1 ano document.cookie = "tema=" + valor + "; max-age=31536000; path=/; SameSite=Lax"; } // PASSO 3: Função ajudante para ler o cookie pelo nome function getCookie(nome) { var match = document.cookie.match(new RegExp("(^| )" + nome + "=([^;]+)")); return match ? decodeURIComponent(match[2]) : null; }

⚠️ Pegadinha Clássica de Iniciante O JavaScript tem uma esquisitice: quando você faz document.cookie = "tema=escuro", parece que você está apagando todos os outros cookies, né? Mas não está! O navegador entende isso como um comando especial de "adicionar ou atualizar" apenas aquela chave específica.

⏳ Banner temporário com contagem regressiva

Sabe aquele aviso de promoção ou alerta de novidade que você fecha e ele só volta a aparecer depois de um tempo? Aqui usamos um cookie com max-age=10 (apenas 10 segundos de vida).

🔍 Como funciona a expiração de um Cookie?

max-age=10
Define o prazo de validade em segundos. O navegador literalmente coloca um cronômetro regressivo: 10, 9, 8... Quando chega a zero, o navegador joga o cookie no lixo automaticamente!
if (bannerFechado === "sim")
Se o cookie ainda existir na memória, adicionamos a classe .escondido (que tem display: none). Quando ele expirar, essa condição não será mais atendida e o banner voltará a aparecer!
HTML Estrutura do banner
<div class="banner" id="banner-boas-vindas"> <div> <strong>👋 Bem-vindo de volta!</strong> <small>Este aviso não aparecerá pelos próximos 10 segundos.</small> </div> <button onclick="fecharBanner()">Fechar</button> </div>
CSS Escondendo o banner
.banner { background: linear-gradient(135deg, #7c3aed, #ec4899); color: #ffffff; padding: 16px 20px; border-radius: 12px; display: flex; justify-content: space-between; align-items: center; gap: 12px; max-width: 480px; } /* Essa classe faz o elemento sumir da tela */ .banner.escondido { display: none; } .banner strong { font-size: 0.95rem; display: block; } .banner small { font-size: 0.78rem; opacity: 0.9; } .banner button { background: rgba(255,255,255,0.25); color: #ffffff; border: 1px solid rgba(255,255,255,0.4); padding: 6px 14px; border-radius: 6px; font-weight: 700; cursor: pointer; }
JS Cronometrando os 10 segundos
// Ao carregar a página: window.addEventListener("load", function() { var bannerJaFechado = getCookie("banner_fechado"); // Se o cookie AINDA existe (não passaram os 10s), esconde o banner if (bannerJaFechado === "sim") { document.getElementById("banner-boas-vindas").classList.add("escondido"); } }); // Ao clicar no botão fechar: function fecharBanner() { // Esconde visualmente agora document.getElementById("banner-boas-vindas").classList.add("escondido"); // Grava o cookie configurando max-age=10 (morre em 10 segundos!) document.cookie = "banner_fechado=sim; max-age=10; path=/; SameSite=Lax"; } function getCookie(nome) { var match = document.cookie.match(new RegExp("(^| )" + nome + "=([^;]+)")); return match ? decodeURIComponent(match[2]) : null; }
⏱️ Faça este teste no DevTools: 1. Clique em "Fechar" no banner lá em cima.
2. No F12 → Application → Cookies, veja o cookie banner_fechado surgir.
3. Repare na coluna Expires / Max-Age. Ela mostra a hora exata da morte dele!
4. Recarregue a página rápido (F5): o banner continua sumido.
5. Espere 10 segundos, aperte F5 de novo: o banner reaparece!

📖 Acessibilidade: Salvando o tamanho de texto preferido

Neste experimento, o valor do cookie não é apenas "sim/não", mas sim uma unidade de CSS completa: 14px, 16px ou 20px.

🔍 Como funciona a função detetive `getCookie()`?

Por que precisamos do getCookie?
Quando você digita document.cookie no console, ele devolve uma frase embolada com todos os cookies grudados: "tema=escuro; banner_fechado=sim; fonte=20px".
A função getCookie("fonte") serve justamente como um "filtro" que vai lá dentro e pinça apenas o pedaço 20px para nós!
elemento.style.fontSize = valor
O JavaScript aplica o valor lido do cookie direto na propriedade de estilo inline do elemento HTML.
HTML Botões com data-attributes
<div class="controle"> <h3>Ajuste o tamanho do texto</h3> <div class="botoes"> <button onclick="mudarFonte('14px', this)" data-fonte="14px">Pequeno</button> <button onclick="mudarFonte('16px', this)" data-fonte="16px" class="ativo">Médio</button> <button onclick="mudarFonte('20px', this)" data-fonte="20px">Grande</button> </div> <div class="texto" id="texto-exemplo"> Este é o texto de exemplo cujo tamanho fica gravado no navegador! </div> </div>
CSS Destaque do botão ativo e transição suave
.controle { background: #ffffff; border: 2px solid #e2e8f0; border-radius: 12px; padding: 20px; max-width: 400px; } .controle .botoes { display: flex; gap: 8px; margin-bottom: 14px; } .controle .botoes button { background: #f1f5f9; color: #334155; border: 2px solid #e2e8f0; padding: 8px 16px; border-radius: 6px; font-weight: 700; cursor: pointer; transition: all 0.2s; } /* O botão do tamanho atual ganha cor roxa */ .controle .botoes button.ativo { background: #7c3aed; color: #ffffff; border-color: #7c3aed; } .texto { color: #334155; line-height: 1.6; font-size: 16px; /* Transição deixa o texto crescer ou encolher suavemente */ transition: font-size 0.2s ease; }
JS Lendo a preferência e sincronizando botões
// 1. Ao carregar, restaura o tamanho salvo window.addEventListener("load", function() { var fonteSalva = getCookie("fonte"); if (fonteSalva) { document.getElementById("texto-exemplo").style.fontSize = fonteSalva; sincronizarBotoes(fonteSalva); } }); // 2. Ao clicar num botão, muda o CSS e salva no Cookie function mudarFonte(tamanho, botaoClicado) { document.getElementById("texto-exemplo").style.fontSize = tamanho; document.cookie = "fonte=" + tamanho + "; max-age=31536000; path=/; SameSite=Lax"; // Atualiza as cores dos botões sincronizarBotoes(tamanho); } // 3. Deixa roxo apenas o botão do tamanho atual function sincronizarBotoes(tamanhoAtual) { var botoes = document.querySelectorAll(".controle .botoes button"); botoes.forEach(function(btn) { if (btn.getAttribute("data-fonte") === tamanhoAtual) { btn.classList.add("ativo"); } else { btn.classList.remove("ativo"); } }); } function getCookie(nome) { var match = document.cookie.match(new RegExp("(^| )" + nome + "=([^;]+)")); return match ? decodeURIComponent(match[2]) : null; }
💡 Dica Ninja de Front-end Repare como usamos SameSite=Lax e path=/ em todos os exemplos. Essa é a boa prática moderna do mercado para garantir que seus cookies funcionem de ponta a ponta sem dor de cabeça no Chrome, Edge, Safari e Firefox.
